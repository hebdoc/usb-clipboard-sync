# USB 剪贴板双向同步工具 (PC <-> Android)

[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Android-green.svg)]()
[![Python 3.8+](https://img.shields.io/badge/Python-3.8+-blue.svg)]()

基于底层 USB 与定制 scrcpy 协议的高性能、零延迟、无感双向剪贴板同步工具。支持 Windows 与 Android（支持澎湃 OS / MIUI / 原生安卓）之间的**文本与图片实时双向互通**。

---

## 🌟 核心特性

- **🚀 毫秒级双向同步**：
  - **电脑 -> 手机**：在电脑端复制任意文字、截图或网页图片，手机端长按即可直接粘贴。
  - **手机 -> 电脑**：
    - **三指截屏秒同步**：手机端任意界面三指截屏，电脑剪贴板 0.1 秒内自动获取，按 `Ctrl + V` 即可粘贴！
    - **相册/文件管理一键发送原图**：相册中选中高清大图 -> 点击【发送】->【发送到电脑】，原图瞬间写入电脑剪贴板。
    - **智能主体抠图复制**：支持小米澎湃 OS（HyperOS）长按主体提取并复制，电脑直接粘贴带透明背景的 PNG 图像。
    - **文字实时同步**：手机复制任意文字，电脑即刻 `Ctrl + V`。
- **🔌 物理链路与内网安全**：
  - 纯 USB 数据线通信，无需通过外网服务器，不走 Wi-Fi，内网办公/涉密开发环境安全无虞。
  - 手机设置为“仅充电”依然能畅通同步，无需挂载 USB 存储，避开企业“禁止 U 盘/移动存储”策略。
- **🔕 纯后台静默托盘**：
  - 运行时任务栏零窗口、零按钮，完全静默驻留在屏幕右下角系统托盘。
  - 双态指示灯（绿色已连接 / 橙色等待中），支持一键呼出/隐藏运行控制台。
- **🔄 断线无感全自动重连**：
  - 拔掉手机或休眠无需重启软件，重新插上数据线后 1~2 秒内秒级自愈并建立通道。
- **📦 离线便携免安装**：
  - 单文件绿色版，内置 ADB 与定制服务端，解压即用，不依赖外部 Python 环境。

## 🚀 快速上手

### 1. 准备工作
1. 使用 USB 数据线连接安卓手机与电脑。
2. 手机开启【开发者选项】与【USB 调试】（并在手机弹出授权提示时勾选“允许”）。

### 2. 运行软件
- **便携版（推荐）**：直接双击 `dist/USB剪贴板双向同步.exe`，程序启动后自动最小化到右下角托盘并弹出就绪气泡。
- **源码运行**：
  ```bash
  pip install -r requirements.txt  # 或安装 pyperclip, pystray, pillow
  python usb_clipboard_sync.py
  ```

---

## 🛠️ 构建与打包

本项目自带全自动化离线便携版构建脚本，执行以下命令即可打包单文件 EXE 与便携 ZIP：

```bash
python build_portable.py
```

构建产物位于 `dist/` 目录：
- `dist/USB剪贴板双向同步.exe`
- `dist/USB剪贴板双向同步-便携版.zip`
